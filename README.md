# Abhishek Singh Tomar Portfolio — Recovered / Reconstructed Source

This repository is a clean reconstruction of the live portfolio at:

- https://abhishek-singh-tomar.vercel.app

## Important recovery note

The original local source was not available and the Vercel deployment was not connected to GitHub. The live deployment exposes compiled/generated output rather than the original editable project, so this project is a maintainable reconstruction rather than a byte-for-byte recovery of the lost source.

The live site identifies itself as **The Daily Developer - Abhishek Singh Tomar Portfolio** and its visual concept corresponds to BuildFolyo's **The Daily Developer** retro newspaper-style portfolio template.

## Run locally

You can open `index.html` directly, or run:

```bash
npm run dev
```

## Deploy to Vercel

Import this repository into Vercel. No build step is required.
