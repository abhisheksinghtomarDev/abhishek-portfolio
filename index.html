Career Report

Engineering Work Centres on Backend Services, Enterprise Logic and Data

Experience spans server-side development, API implementation, persistence workflows, issue resolution and software maintenance in production-oriented environments.

Across professional software work, the central responsibility has been backend engineering in the .NET ecosystem. This includes implementing server-side features, translating requirements into application logic and maintaining code that remains understandable after delivery.

REST APIs form a major part of the toolkit, with attention to request/response contracts, service-layer organization, validation, data retrieval and database interaction. ASP.NET Core is used as the primary web framework for application development.

Entity Framework and LINQ support persistence and querying, while SQL Server provides the relational data layer. The work frequently involves navigating existing codebases, tracing defects and making targeted changes without destabilizing surrounding functionality.

Exposure to ABP Framework contributes experience with structured enterprise application patterns, while Web Services and integration-focused work provide familiarity with system-to-system communication.

WPF experience adds desktop application exposure, and Angular experience provides context for how frontend clients consume backend APIs and depend on consistent data contracts.

Current development priorities include deeper system design knowledge, stronger DSA problem solving and Azure cloud fundamentals to move from implementation-focused backend work toward broader engineering ownership.
